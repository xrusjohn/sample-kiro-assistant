# 1 Setup Amazon Connect

1 Setup Amazon ConnectModule Overview
In this module, you will build and configure an Amazon Connect Omnichannel cloud contact center. You will create a contact center, or you will have the option to use the Amazon Connect instance provided for this workshop.
Module Sections

Setup Amazon Connect Instance: Each instance contains all the resources and settings related to your contact center.
Setup Task Queue Flow: The queue is where contacts wait before they reach an agent.
