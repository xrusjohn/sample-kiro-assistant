# 5. Exercise 4 - Case Rules

5. Exercise 4 - Case RulesThis module needs a basic knowledge of Amazon Connect Cases and Amazon Connect Customer Profiles.
Amazon Connect Cases
Amazon Connect Cases allows customer service teams to track, collaborate, and resolve customer issues efficiently. Each case represents a customer's specific issue, capturing details such as the problem, steps taken, interactions, and the final outcome. You can enable Cases for your contact center without any integration work. Cases can be automatically created when contacts come in, and relevant information from the customer can be collected and displayed. Alternatively, agents can manually create cases. When an agent accepts a contact, they have immediate access to the case context, enabling them to start resolving the issue promptly. Additionally, you can create tasks within a case to track and route follow-up steps required for resolution.
For more information on Amazon Connect Cases benefits and frequently asked questions (FAQs), please see Amazon Connect Cases  page.

Amazon Connect Customer Profiles
Contact centers must understand customer context to deliver excellent service. Amazon Connect Customer Profiles helps create unified customer profiles with the latest data, enabling personalized customer service. With minimal effort, data from third-party apps like Salesforce, ServiceNow, Zendesk, Marketo, and Amazon S3 can be integrated to build comprehensive customer profiles using pre-built connectors.
For more information on Amazon Connect Customer Profiles benefits and frequently asked questions (FAQs), please see Amazon Connect Customer Profiles  page.
