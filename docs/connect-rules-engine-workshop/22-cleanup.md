# Cleanup

CleanupAWS Event provided accountIf you have used an AWS Event provided account, all resources will automatically be deleted for you.
Personal accountIf you have used your personal account, delete resources created by the CloudFormation template to avoid incurring costs for any resources retained. Please see Amazon Connect Pricing 
ImportantEmpty the S3 folder manually before deleting the CloudFormation, or else the deletion will fail.

Go to the CloudFormation service.
Select the stacks you have chosen for the deployment and click on Delete.
