# Exercise 4.1.2 - Configure a Case template

Exercise 4.1.2 - Configure a Case templateCase templates are structured forms that guide agents to gather and document relevant information for specific types of customer issues. For instance, a template for vehicle damage claims would require agents to fill out specific fields when assisting customers in filing insurance claims. For more information on Case templates, see How case templates look in the agent application 
NoteCases are always created based on a template.
Create Case templates

In the AWS Services search box, type Amazon Connect.

Choose Amazon Connect, select the Access URL for the instance that was created.

You are now on the login page for your Amazon Connect instance. Please log in with the administrator username and password you set up for the instance.

You are now on the Amazon Connect admin console.

On the left navigation menu, choose Agent applications > Case templates.

Choose + New Template.

Type a Template name and click on Save. Keeping other fields as default.

Template created.

Congratulations!You have created a case template. Proceed to the next exercise to explore how to setup case event streams.
