# 2. Exercise 1 - Real Time Metrics Rules

2. Exercise 1 - Real Time Metrics RulesRules offers real-time alerts about customer experience and agent performance. This allows supervisors to assist agents during customer interactions. Businesses can automate alerts and actions based on contact center metrics like long queue wait times or a shortage of available agents. This automation helps streamline operations.
Amazon Connect allows creating rules that invoke specific actions based on defined conditions. These rules can be set up through the Amazon Connect console without any coding required by contact center managers and supervisors.
NoteFor the complete list of available metrics for rule setup refer Create alerts on real-time metrics in Amazon Connect Contact Lens 
Module Overview
This module teaches you how to create a real-time metrics rule in Amazon Connect. You will set up a rule to monitor agent activity state metric. If an agent's activity state changes to "missed" for more than one minute, the rule will invoke actions to send an email and create a task for the supervisor.
