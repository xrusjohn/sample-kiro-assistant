# Exercise 4.1.1 - Create Case Domain

Exercise 4.1.1 - Create Case DomainNoteA case is always associated with a customer profile. To use cases, you need to have Customer Profiles enabled. For this workshop, Customer Profiles is already enabled on the provided Amazon Connect instance.
How to enable Amazon Connect Cases

Open the Amazon Connect console  .

Select the Amazon Connect instance deployed in Setup Amazon Connect Environment Exercise.

On the left navigation menu, choose Customer Profiles and verify it is enabled for your instance.

On the left navigation menu, choose Cases.

On the Cases page, choose Add domain.

On the add domain page, enter a unique, friendly Domain name that's meaningful to you, such as your organization name.

Click on Add domain.

NoteCopy the domain ID, which is the last part of the ARN indicated by the arrow, as you will need it in the next section.
Congratulations!You have created a Cases domain for your Amazon Connect instance. Proceed to the next exercise to create a case template.
