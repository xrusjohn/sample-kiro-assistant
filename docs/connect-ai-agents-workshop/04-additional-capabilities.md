# Additional AI Agent Capabilities

Additional AI Agent CapabilitiesThe Additional AI Agent Capabilities section provides advanced modules for exploring AI capabilities beyond the core Agent Assistance and Self-Service use cases. These modules cover specialized AI features for cases, customer profiles, email, and tasks that enhance both agent productivity and customer self-service experiences.
What You'll Learn
In this section, you'll explore advanced AI capabilities that extend the foundation you built in the core tracks:

Cases AI Capabilities: AI-powered case summarization and 1P MCP Cases tools for creating, updating, and searching cases
Customer Profiles AI Capabilities: Predictive Insights and Sales AI Agent for personalized customer recommendations
Email AI Capabilities: Generative AI-powered email conversation overviews and suggested responses
