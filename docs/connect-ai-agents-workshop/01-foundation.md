# Foundation Module

Foundation ModuleThe Foundation module provides the shared infrastructure and core concepts needed for both the Agent Assistance and Self-Service learning tracks. Complete this module before proceeding to your chosen track.
What You'll Learn
In this module, you'll establish the foundational knowledge and infrastructure required to build AI-powered customer experiences with Amazon Connect:

Key Concepts: Understand Orchestration AI Agents, tool types, and how Agent Assistance and Self-Service use cases differ
Security Profiles: Configure permissions for AI Agent access and tool invocation
Deployment Options: Choose between Workshop Account (pre-deployed) or BYO Account deployment paths
Knowledge Base Configuration: Set up knowledge sources using S3, Salesforce, ServiceNow, or Bedrock KB connectors
MCP Server Setup: Configure AgentCore Gateway for third-party tool integration
Flow Module Setup: Create reusable contact flow components that AI Agents can invoke as tools

Why Foundation First?
Both Agent Assistance and Self-Service tracks use the same underlying infrastructure:

Same AI Agent Type: Both tracks use Orchestration AI Agents that can reason, plan, and invoke tools
Shared Knowledge Bases: The same knowledge content serves both human agents and customer self-service
Common Tool Framework: MCP servers and Flow Modules work with both Agent Assistance and Self-Service agents
Unified Security Model: Security Profiles control tool access for all AI Agent types

By completing the Foundation module first, you'll have all the infrastructure in place to focus on track-specific configurations.
