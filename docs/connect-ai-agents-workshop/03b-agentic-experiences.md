# Agentic Experiences

Agentic ExperiencesOverview
Agentic Experiences are optional enhancements that make your Self-Service AI Agent interactions more natural and engaging. These advanced capabilities go beyond basic AI Agent configuration to provide customers with more sophisticated, human-like experiences.
This section covers two enhancements:

Nova Sonic Voice - Enable natural, generative voice for your AI Agent responses
AI Message Streaming - Display AI responses progressively as they're generated, improving perceived responsiveness

Why Agentic Experiences Matter
While your Self-Service AI Agent works effectively with standard text-to-speech and complete message delivery, Agentic Experiences elevate the customer experience:

Nova Sonic Voice: Customers hear natural, expressive speech that sounds more human-like than traditional text-to-speech
AI Message Streaming: Customers see responses appearing in real-time, creating a more interactive and engaging chat experience

Optional Enhancements
These enhancements are optional and not required for a functional Self-Service AI Agent. You can:

Implement both enhancements for the most sophisticated experience
Implement only Nova Sonic for voice-focused interactions
Implement only AI Message Streaming for chat-focused interactions
Skip both and use standard text-to-speech and complete message delivery

Recommended Order:

Start with Nova Sonic Voice if you're building a voice-first experience
Then explore AI Message Streaming if you also support chat
Or start with AI Message Streaming if you're chat-focused
